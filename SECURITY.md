# Security policy

Please report suspected vulnerabilities privately through GitHub's security
advisory feature for `HUDongpin/hina`. Do not include practice or research data
that you are not authorized to share.

`hina-js` performs all workbench file processing locally in the browser. The
package does not upload files, make analysis requests, execute workbook
formulas, or include telemetry. Consumers remain responsible for validating
and protecting the datasets they choose to load.
